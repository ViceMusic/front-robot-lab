## 新版：简洁的 Three.js 3D 展示

机械臂显示为立体模型，但它仍是**平面双关节机械臂**，不是任意三维空间的 IK。数学平面 (x,y) 映射为 Three.js 世界 (x,高度,-y)。

- **FK（控制关节）**：按住 A / D 转动关节 1，S / W 转动关节 2。可以同时按 D + W，观察两个关节同时旋转时，末端如何移动。
- **IK（控制末端）**：按方向键移动目标，两个关节自动配合；也能点击场景设置目标。试着一直按右键，末端在数学平面中沿直线走，关节却不是匀速旋转。
- **Tab** 切换 FK / IK；**E** 切换肘上 / 肘下；**Shift + 方向/关节键** 慢速移动。
- **R** 重置姿态；**V** 切换俯视 / 立体；**C** 清除轨迹。
- 拖动场景旋转视角，滚轮缩放；下面显示角度、实际坐标与目标坐标。展开“看一点公式”可查看计算及 IK 的 FK 回代误差。
- 点击场景后键盘生效，按 **Esc** 退出键盘控制。Shift + Tab 保留浏览器焦点导航；失焦自动释放按键。手机可按住屏幕中的按键操作。

绿色圆环是目标，橙色球是实际末端。目标到原点的距离必须满足 **0.25 ≤ r ≤ 2.25 m**；不可达时目标变红，机械臂保留最后有效姿态，不会偷偷把目标投影到边界。

这是纯运动学演示：IK 立即给出姿态，不模拟动力学或中间运动。切换肘部解会瞬间变姿态并清除轨迹。连杆长度固定为 1.25 m 和 1.00 m；θ₂ 是相对第一连杆的角度，逆时针为正。

新版需要浏览器 WebGL；只进行浏览器图形渲染，没有 GPU 训练或后端任务。如果 WebGL 不可用，可打开 **index-2d.html**。Three.js 固定为 0.160.1 的经典脚本构建，以支持 file:// 直接打开；MIT 许可证见 vendor/THREE-LICENSE.txt。

## 怎么玩

1. **FK**：切换「直接 FK」，拖动 θ₁ / θ₂；机械臂立即显示对应姿态，右下方给出公式及末端坐标。
2. **IK**：在画布点击或拖动目标，也可输入 x/y 后点击「求解 IK」。切换肘上/肘下，观察同一个末端坐标对应的两种姿态。
3. **PID**：切换「PID 运动」，选「平稳」或「超调」，点击「阶跃实验」。滑块设置的是目标角，实体机械臂是实际角；观察下方目标虚线、实际实线和末端误差。
4. 可调连杆长度、Kp/Ki/Kd；支持暂停、重置、清除历史轨迹。曲线显示最近 20 秒的仿真时间。

## 数学约定

- 世界坐标 x 向右、y 向上；角度逆时针为正。θ₁ 相对于 x 轴，θ₂ **相对于第一连杆**。屏幕 y 向下仅在绘图转换时反转。
- 长度与坐标单位为米。UI 角度为度，数学和 PID 全部用弧度。
- FK：`x=L1*cos(q1)+L2*cos(q1+q2)`，`y=L1*sin(q1)+L2*sin(q1+q2)`。
- IK：`c2=(x²+y²-L1²-L2²)/(2*L1*L2)`，`q2=±acos(c2)`，`q1=atan2(y,x)-atan2(L2*sin(q2),L1+L2*cos(q2))`。
- 可达条件：`|L1-L2| ≤ hypot(x,y) ≤ L1+L2`。不满足时拒绝下发，红色十字显示不可达请求，控制器继续跟随上一有效执行目标；误差曲线始终相对**执行目标**。
- 肘上使用负 q2，肘下使用正 q2；这里的“上/下”相对于基座指向目标的方向，并非所有象限中的绝对屏幕上下。
- 边界奇异姿态两解合并；等长连杆到原点时 q1 有无穷多解，保留当前 q1。每次求解都用 FK 验证，并显示数值残差。
- 使用距离当前角度最近的 2π 等价解，避免无谓绕圈。滑块显示 −180°～180° 的等价角；实际角、控制目标及曲线可连续超出该区间。模型不设机械关节限位或自碰撞。

## 控制器不是瞬移

两关节独立简化为 `J*qddot=tau-b*qdot`：J=[1,0.75]，b=[0.7,0.55]，不含重力和连杆间耦合。连杆长度只改变运动学，不重新计算惯量。

控制律：`tau=Kp*(q_target-q)+Ki*integral(error)-Kd*qdot`。D 项采用测量速度，避免目标阶跃造成微分冲击；力矩限制 ±45 N·m，积分限制 ±3 rad·s，并使用条件积分防止 windup。新目标或增益修改会清零积分。两个关节共用 UI 增益。

固定积分步长 1/240 秒，采用半隐式 Euler。采样频率 25 Hz，渲染使用 requestAnimationFrame；页面退到后台时不补算长时间间隔，避免数值爆炸。低刷新率时仿真可能慢于墙上时钟。

**直接 FK 模式旁路 PID**；暂停只冻结时间推进，仍可编辑目标，直接 FK 模式仍可查看新姿态。
