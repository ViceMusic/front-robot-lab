LIVE CALCULATIONS
A / 正向运动学 FK

x = L₁ cos θ₁ + L₂ cos(θ₁ + θ₂)
y = L₁ sin θ₁ + L₂ sin(θ₁ + θ₂)

输入实际关节角 → 输出实际末端位置；三角函数使用弧度。
B / 解析逆运动学 IK

c₂ = (x² + y² − L₁² − L₂²) / (2L₁L₂)
θ₂ = ±acos(c₂)
θ₁ = atan2(y,x) − atan2(L₂ sin θ₂, L₁+L₂ cos θ₂)

C / 关节动力学 + PID

e = θ* − θ　　τ = Kp·e + Ki·∫e dt − Kd·θ̇
J·θ̈ = τ − b·θ̇

两关节独立；无重力、无连杆耦合。J = [1, 0.75]，b = [0.7, 0.55]。这是教学近似，不是完整机器人动力学。
