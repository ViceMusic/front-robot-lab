# Robot Lab 学习笔记

这里放自己的练习记录、备注、问题和灵感，使用 Markdown 文件即可。

建议按主题或日期命名，例如：

- `2026-10-15-first-play.md`：第一次操作的观察
- `fk-and-ik.md`：正运动学与逆运动学理解
- `questions.md`：以后想研究的问题

可以从这几个问题开始：

1. 同时转动两个关节时，末端画出什么轨迹？
2. 为什么末端沿直线移动时，两个关节的转速会变化？
3. 同一个目标为什么有肘上 / 肘下两种姿态？
4. 在伸直、折叠或不可达边界附近，会发生什么？

注意：提交到公开 GitHub 仓库的笔记会公开。不要放密码、密钥或私人信息；只想本机保存的内容可以放到已被 Git 忽略的 `notes/private/` 中。
